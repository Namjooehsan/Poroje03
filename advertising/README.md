# پوشه تبلیغات — نسخه انتقالی

این پوشه برای مستندسازی کمپین‌های تبلیغاتی نسخه قدیمی Global Post Engine نگهداری می‌شود. اجرای کمپین و انتشار باید فقط از هسته مرکزی `Namjooehsan/telegram-market-bot` انجام شود تا مخاطب پیام تکراری دریافت نکند.

هر محتوای حمایت‌شده باید برچسب تبلیغاتی، سفارش/قرارداد معتبر، بازه انتشار و تأیید مدیر داشته باشد. این پوشه هیچ کمپین یا انتشار فعالی ایجاد نمی‌کند.
