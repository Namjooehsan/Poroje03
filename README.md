# Global Post Engine

ربات دریافت، بازنویسی و زمان‌بندی انتشار محتوا.

- ورودی امن از طریق POST /api/posts
- دامنه محتوا: global یا iran_only
- سه موج انتشار در روزهای ۱، ۱۱ و ۲۱؛ بدون تکرار روزانه و با ثبت سابقه
- زمان‌بندی از طریق Metricool API روی شبکه‌های واقعاً متصل
- محتوای دارای برچسب «فقط ایران» به شبکه‌های جهانی ارسال نمی‌شود.
- اگر مقصد ایرانی معتبر تنظیم نشده باشد، محتوای فقط ایران مسدود/در صف می‌ماند.
- تشخیص تکراری، محدودیت فایل، ثبت خطا و بررسی نیاز رسانه انجام می‌شود.

محدودیت جغرافیایی: انتشار ارگانیک در شبکه‌های جهانی امکان تضمین «فقط ایران» را نمی‌دهد. برای این دامنه باید مقصد ایرانی با API رسمی متصل شود یا از تبلیغات دارای هدف‌گیری جغرافیایی استفاده شود.

## نصب
Python 3.12+
pip install -r requirements.txt
cp .env.example .env
python app.py

## تنظیمات امن
APP_SECRET: کلید تصادفی برای endpoint ورودی
METRICOOL_API_TOKEN: توکن API از Account Settings > API
METRICOOL_USER_ID و METRICOOL_BLOG_ID: شناسه حساب و برند
METRICOOL_TIMEZONE: پیش‌فرض Asia/Tehran
GLOBAL_PROVIDERS: شبکه‌های جهانی متصل
IRAN_PROVIDERS: فقط آداپتورهای ایرانی واقعاً پیاده‌سازی‌شده
AUTO_PUBLISH: پس از تکمیل و تست دسترسی‌ها true شود

Metricool API طبق مستندات رسمی فقط در طرح Advanced و Custom ارائه می‌شود. توکن‌ها را فقط در Secrets میزبان قرار دهید، نه در مخزن.

## API ورودی
POST /api/posts با هدر X-App-Secret و بدنه JSON:
{"text":"متن پست","scope":"global","media":["https://example.com/image.jpg"]}

برای ایران فقط: scope برابر iran_only یا وجود عبارت «فقط ایران» در متن.

در نسخه فعلی اتصال مقصدهای ایرانی و ورودی تلگرام هنوز باید با اطلاعات دسترسی معتبر تکمیل شوند. تا آن زمان هیچ ادعای انتشار زنده وجود ندارد.


## دریافت پست از تلگرام
- متغیر TELEGRAM_BOT_TOKEN در نسخه فعلی برای ارسال پاسخ به تلگرام لازم نیست؛ وب‌هوک ورودی با هدر محرمانه Telegram اعتبارسنجی می‌شود.
- TELEGRAM_ADMIN_IDS باید شامل شناسه عددی حساب‌هایی باشد که مجاز به ارسال محتوا هستند.
- TELEGRAM_WEBHOOK_SECRET باید یک رشته تصادفی قوی باشد.
- پس از استقرار روی HTTPS، وب‌هوک ربات را با Telegram setWebhook به آدرس https://YOUR_HOST/telegram/webhook متصل کنید و secret_token را برابر TELEGRAM_WEBHOOK_SECRET قرار دهید.
- در حال حاضر ورودی تلگرام متن و کپشن را می‌پذیرد؛ برای رسانه باید URL عمومی HTTPS در API وب وارد شود. فایل‌های رسانه‌ای تلگرام هنوز به‌صورت خودکار به Metricool منتقل نمی‌شوند.

## وضعیت فعلی
مخزن شامل API ورودی، پایگاه داده SQLite، مسیر امن تلگرام، زمان‌بندی سه‌مرحله‌ای و اتصال برنامه‌ای به Metricool است. این مخزن هنوز روی میزبان اجرا نشده و کلید API Metricool، شناسه کاربر/برند و secretهای محیطی در دسترس نیستند. بنابراین هیچ پست واقعی منتشر نشده است.
