# Global Post Engine

موتور دریافت محتوا، ساخت سه نسخه و زمان‌بندی انتشار در سه نوبت طی یک ماه (روزهای ۱، ۱۱ و ۲۱).

## قابلیت‌ها
- ورودی امن با `POST /api/posts` و هدر `X-App-Secret`
- ورودی تلگرام با وب‌هوک امن و فهرست مجاز ادمین‌ها
- تشخیص محتوای «فقط ایران» و جلوگیری از ارسال آن به شبکه‌های جهانی
- ذخیره پست‌ها و نتایج در SQLite
- جلوگیری از زمان‌بندی تکراری در retry
- صف قابل بازیابی برای پست‌هایی که پیش از تنظیم API token دریافت شده‌اند
- حالت پیش‌فرض امن: ساخت Draft به‌جای انتشار مستقیم

## پیش‌نیازها و راه‌اندازی
Python 3.12+
```bash
pip install -r requirements.txt
cp .env.example .env
python app.py
```

## متغیرهای محیطی
- `APP_SECRET`: کلید تصادفی طولانی برای API ورودی
- `TELEGRAM_ADMIN_IDS`: شناسه عددی ادمین‌های مجاز تلگرام، جداشده با کاما
- `TELEGRAM_WEBHOOK_SECRET`: secret token وب‌هوک تلگرام
- `METRICOOL_API_TOKEN`: REST API Access Token متریکول
- `METRICOOL_USER_ID`: شناسه حساب Metricool
- `METRICOOL_BLOG_ID`: شناسه برند Metricool
- `METRICOOL_TIMEZONE`: منطقه زمانی برند؛ پیش‌فرض Asia/Tehran
- `GLOBAL_PROVIDERS`: مقصدهای جهانی متصل و مجاز در Metricool
- `IRAN_PROVIDERS`: فقط آداپتورهای ایرانی که واقعاً پیاده‌سازی و تست شده‌اند
- `AUTO_PUBLISH`: مقدار پیش‌فرض false؛ در این حالت پست‌ها Draft می‌شوند

## دریافت کلید Metricool
در نسخه فعلی Metricool، API فقط در پلن‌های Advanced و Custom موجود است. مسیر:
Account Settings → API → REST API Access Token

هر درخواست API به سه مقدار نیاز دارد: توکن در هدر `X-Mc-Auth` و `userId` و `blogId` در query string. توکن را در GitHub یا فایل‌های مخزن قرار ندهید؛ فقط در متغیرهای محرمانه میزبان تنظیم کنید.

راهنمای رسمی:
https://help.metricool.com/basic-guide-for-api-integration-r97af

## API ورودی پست
`POST /api/posts`

هدر:
`X-App-Secret: YOUR_APP_SECRET`

بدنه نمونه:
```json
{
  "text": "متن پست",
  "scope": "global",
  "media": ["https://example.com/public-image.jpg"]
}
```

برای محتوای ایران فقط، مقدار `scope` را `iran_only` قرار دهید یا عبارت «فقط ایران» را در متن بگذارید.

## تلاش مجدد صف
پس از تنظیم توکن و شناسه‌ها، برای پردازش مجدد پست‌های منتظر:
`POST /api/retry-pending`

این مسیر نیز به هدر `X-App-Secret` نیاز دارد. رکوردهایی که قبلاً با موفقیت زمان‌بندی شده‌اند در retry دوباره ارسال نمی‌شوند.

## تلگرام
پس از استقرار روی HTTPS، وب‌هوک را روی:
`https://YOUR_HOST/telegram/webhook`
تنظیم کنید و `secret_token` را برابر `TELEGRAM_WEBHOOK_SECRET` قرار دهید. فقط شناسه‌های موجود در `TELEGRAM_ADMIN_IDS` مجازند.

در نسخه فعلی تلگرام متن و کپشن را دریافت می‌کند؛ دانلود و انتقال خودکار فایل‌های رسانه‌ای تلگرام هنوز تکمیل نشده است.

## محدودیت‌ها و موارد باقی‌مانده
- مقصدهای ایرانی مانند ایتا، بله، روبیکا و سروش هنوز آداپتور رسمی ندارند؛ بنابراین پست‌های «فقط ایران» تا زمان اتصال مقصد معتبر در صف مسدود می‌مانند.
- انتشار ارگانیک در شبکه‌های جهانی، محدودیت جغرافیایی «فقط ایران» را تضمین نمی‌کند.
- بازنویسی چندزبانه مبتنی بر هوش مصنوعی هنوز متصل نشده؛ نسخه فعلی سه تغییر متنی ساده می‌سازد.
- انتشار YouTube به فایل ویدئو و متادیتای لازم نیاز دارد و در این نسخه غیرفعال است.
- پیش از فعال‌کردن `AUTO_PUBLISH=true` باید یک پست آزمایشی Draft بررسی شود.
- سرویس هنوز به Railway مستقر نشده است؛ ایجاد پروژه جدید با محدودیت منابع پلن رایگان Railway متوقف شد. سرویس‌های موجود کاربر دست‌نخورده باقی مانده‌اند.

## وضعیت امنیتی
هیچ توکن یا کلید واقعی نباید در مخزن، پیام عمومی یا کد سمت کاربر قرار بگیرد. `APP_SECRET` و `TELEGRAM_WEBHOOK_SECRET` باید مقادیر تصادفی قوی و مستقل باشند.
