# پوشه همکاری — نسخه انتقالی

سرنخ‌های همکاری، ناشران، شرکای فروش و قراردادهای بازاریابی این نسخه صرفاً به‌عنوان مستندات تاریخی یا پیش‌نویس ثبت می‌شوند. مخزن عملیاتی و مرجع پیگیری همکاری‌ها `Namjooehsan/telegram-market-bot/collaboration/` است.

برای جلوگیری از تداخل، تماس، قرارداد، ثبت کمیسیون یا انتشار از این مخزن انجام نشود. هر اقدام نیازمند اعتبارسنجی شریک و تأیید مدیر در سامانه مرکزی است.
